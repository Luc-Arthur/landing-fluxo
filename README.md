# 💸 Fluxo — Landing page d'un SaaS financier pour MEI

Landing page de conversion pour **Fluxo**, une application fictive qui aide les micro-entrepreneurs brésiliens (MEI) à gérer leur trésorerie, leur limite de chiffre d'affaires et le paiement du DAS.

🔗 **Démo en ligne :** [luc-arthur.github.io/landing-fluxo](https://luc-arthur.github.io/landing-fluxo/)

![Aperçu de la landing page Fluxo](docs/accueil.png)

> ℹ️ Projet de démonstration pour mon portfolio : la marque et les données sont fictives. Le contenu est en portugais du Brésil, la langue du public visé.

---

## ✨ Ce que contient la page

- **Hero** avec maquette de téléphone animée (graphique, transactions, cartes flottantes)
- **Bandeau défilant** des fonctionnalités
- **Section « problème »** qui parle directement aux douleurs du MEI
- **Grille de fonctionnalités** en bento
- **« Comment ça marche » en 3 étapes**
- **Tarifs** avec offre gratuite et offre mise en avant
- **FAQ** en accordéon, sans JavaScript (`<details>`)
- **Appel à l'action final**

## 🎨 Choix de design

- Typographie contrastée : **Fraunces** (serif expressive) pour les titres, **Figtree** pour le texte
- Palette papier / vert profond / citron vert / orange, avec une texture de grain en SVG
- Boutons à ombre décalée façon néo-brutalisme
- Animations d'apparition au scroll (`IntersectionObserver`) et respect de `prefers-reduced-motion`
